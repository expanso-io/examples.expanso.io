# Step 1: Encrypt Credit Card Data

This step selects the synthetic card number for encryption while retaining authored display fields such as the last four digits and brand. Review those retained values independently before adapting the pattern.

## The Goal

You will transform the `payment` object by:

1.  Encrypting the `card_number` into a new `card_number_encrypted` field.
2.  Extracting the `card_last_four` and `card_brand` for analytics.
3.  Deleting the original, plaintext `card_number`.

**Input Snippet:**

```json
{
  "payment": {
    "card_number": "4532-1234-5678-9010",
    "expiration": "12/27"
  }
}
```

**Desired Output Snippet:**

```json
{
  "payment": {
    "expiration": "12/27",
    "card_number_encrypted": "AES256GCM:v1:...",
    "card_last_four": "9010",
    "card_brand": "visa"
  }
}
```

## Implementation

1.  **Start with the Foundation:** Copy `encryption-foundation.yaml` to a new file, `encrypt-card.yaml`.

    ```bash
    cp examples/data-security/encryption-foundation.yaml encrypt-card.yaml
    ```

2.  **Add the Encryption Logic:** Open `encrypt-card.yaml` and add the following `mapping` processor to the `pipeline` section. This single processor performs the entire transformation.

    ```yaml title="Add this to the 'processors' array in encrypt-card.yaml"
    - mapping: |
        root = this
        let key = env("CARD_ENCRYPTION_KEY_HEX").decode("hex")
        let key = if $key.length() != 32 {
          throw("Expected a 32-byte AES key")
        } else { $key }
        let clean_card = this.payment.card_number.re_replace_all("[^0-9]", "")
        let number_nonce = uuid_v4().replace_all("-", "").slice(0, 24)
        let name_nonce = uuid_v4().replace_all("-", "").slice(0, 24)

        root.payment.card_number_encrypted = if this.payment.card_number != null {
          this.payment.card_number.encrypt_aes(
            "gcm", $key, $number_nonce.decode("hex")
          ).encode("base64")
        }
        root.payment.card_number_nonce = if this.payment.card_number != null {
          $number_nonce
        } else { deleted() }
        root.payment.card_last_four = clean_card.slice(-4)
        root.payment.card_brand = match {
          clean_card.has_prefix("4") => "visa"
          clean_card.re_match("^5[1-5]") => "mastercard"
          clean_card.re_match("^3[47]") => "amex"
          clean_card.re_match("^6(?:011|5)") => "discover"
          _ => "unknown"
        }
        root.payment.cardholder_name_encrypted = if this.payment.cardholder_name != null {
          this.payment.cardholder_name.encrypt_aes(
            "gcm", $key, $name_nonce.decode("hex")
          ).encode("base64")
        }
        root.payment.cardholder_encrypted = root.payment.cardholder_name_encrypted
        root.payment.cardholder_name_nonce = if this.payment.cardholder_name != null {
          $name_nonce
        } else { deleted() }
        root.payment = root.payment.without(
          "card_number", "cvv", "cardholder_name"
        )
    ```

    _Note: Set `CARD_ENCRYPTION_KEY_HEX` to a deployment-managed, 32-byte key encoded as hexadecimal._

3.  **Deploy and Test:**

    ```bash
    # Send the sample payment data from the setup step
    curl -X POST http://localhost:8080/payments/transactions \
      -H "Content-Type: application/json" \
      -d @/tmp/encryption-test/sample-payment.json
    ```

4.  **Verify:** Check your logs. You will see that the `card_number` field is gone, replaced by `card_number_encrypted`, `card_last_four`, and `card_brand`.

The reference now shows the payment-field selection pattern. It has not been executed or assessed against a deployed threat model.

Supply the endpoint, credential, trusted-CA, KMS, and database variables used by these fragments from deployment configuration. `EXAMPLE_OUTPUT_PATH` must name writable persistent storage; use workload identity for S3 access.
