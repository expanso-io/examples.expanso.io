# Complete Pipeline

<CopyPipelineButton pipeline={pipelineYaml} />

This pipeline combines all field encryption techniques from this tutorial:

- **Credit card encryption** - AES-256-GCM encryption, preserve last 4 digits
- **PII encryption** - Encrypt emails, SSNs while preserving domain/last-4
- **Address encryption** - Encrypt street, preserve city/state/ZIP prefix
- **Audit metadata** - Track encryption timestamp, key version

The mappings generate a separate 12-byte nonce for each encrypted field and
base64-encode both nonce and ciphertext. Keep each nonce with its ciphertext;
decryption requires both, plus the matching key version. Key rotation and
authorization remain responsibilities of the integrating system.

## Input example

The displayed tutorial configuration reads `CARD_KEY`, `PII_KEY`, and
`ADDR_KEY`. Supply valid AES keys through your environment before adapting it.

```bash
# Send data with sensitive fields
curl -X POST http://localhost:8080/transactions \
  -H "Content-Type: application/json" \
  -d '{
    "transaction_id": "txn_001",
    "payment": {
      "card_number": "4532123456789010",
      "cvv": "123",
      "cardholder_name": "Synthetic User"
    },
    "customer": {
      "email": "synthetic@example.com",
      "ssn": "123-45-6789",
      "phone": "4155550100"
    },
    "address": {
      "street": "123 Main St",
      "city": "San Francisco",
      "state": "CA",
      "zip": "94102"
    }
  }'

# Output: card_number → encrypted, email → encrypted, ssn → encrypted
# Analytics-safe fields preserved: last_four, domain, city, state, zip_prefix
```
