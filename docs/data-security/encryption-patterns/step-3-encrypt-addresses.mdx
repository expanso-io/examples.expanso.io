# Pattern 3: Encrypting Location Data

This pattern demonstrates how to protect precise location information, like a street address, while preserving less sensitive geographic data (like a city or state) for regional analytics.

## The Pattern

For any object containing a physical address:

1.  **Encrypt** the fields that provide precise location, such as `street` and the full `zip` code.
2.  **Extract** and **Preserve** fields that are useful for analytics but do not identify an individual, such as `city`, `state`, `country`, and the `zip_prefix` (the first 3 digits of a US zip code).
3.  **Delete** the original, plaintext sensitive fields.

## Implementation

Append this as a separate item in `pipeline.processors` after the processor from Step 2. Each processor receives the previous processor's output, so `root = this` preserves earlier ciphertext and deletions. Keep the earlier processors in order.

```yaml
pipeline:
  processors:
    - mapping: |
        let key = env("ADDRESS_ENCRYPTION_KEY_HEX").decode("hex")
        let key = if $key.length() != 32 { throw("Expected a 32-byte AES key") } else { $key }
        root = this

        # Extract ZIP prefixes for demographic clustering
        root.billing_address.zip_prefix = if this.billing_address.zip != null {
          this.billing_address.zip.re_replace_all("[^0-9]", "").slice(0, 3)
        }
        root.shipping_address.zip_prefix = if this.shipping_address.zip != null {
          this.shipping_address.zip.re_replace_all("[^0-9]", "").slice(0, 3)
        }

        # Determine metro areas for regional analytics
        let billing_metro = if this.billing_address.city != null {
          match {
            this.billing_address.city.lowercase().re_match(".*(san francisco|sf).*") => "sf_bay_area"
            this.billing_address.city.lowercase().re_match(".*(los angeles|la).*") => "la_metro"
            _ => "other_urban"
          }
        } else { null }

        # Encrypt precise location data
        let billing_address_street_nonce = uuid_v4().replace_all("-", "").slice(0, 24)
        root.billing_address.street_encrypted = if this.billing_address.street != null {
          this.billing_address.street.encrypt_aes("gcm", $key, $billing_address_street_nonce.decode("hex")).encode("base64")
        }
        root.billing_address.street_nonce = if this.billing_address.street != null { $billing_address_street_nonce } else { deleted() }
        let billing_address_zip_nonce = uuid_v4().replace_all("-", "").slice(0, 24)
        root.billing_address.zip_encrypted = if this.billing_address.zip != null {
          this.billing_address.zip.encrypt_aes("gcm", $key, $billing_address_zip_nonce.decode("hex")).encode("base64")
        }
        root.billing_address.zip_nonce = if this.billing_address.zip != null { $billing_address_zip_nonce } else { deleted() }
        let shipping_address_street_nonce = uuid_v4().replace_all("-", "").slice(0, 24)
        root.shipping_address.street_encrypted = if this.shipping_address.street != null {
          this.shipping_address.street.encrypt_aes("gcm", $key, $shipping_address_street_nonce.decode("hex")).encode("base64")
        }
        root.shipping_address.street_nonce = if this.shipping_address.street != null { $shipping_address_street_nonce } else { deleted() }
        let shipping_address_zip_nonce = uuid_v4().replace_all("-", "").slice(0, 24)
        root.shipping_address.zip_encrypted = if this.shipping_address.zip != null {
          this.shipping_address.zip.encrypt_aes("gcm", $key, $shipping_address_zip_nonce.decode("hex")).encode("base64")
        }
        root.shipping_address.zip_nonce = if this.shipping_address.zip != null { $shipping_address_zip_nonce } else { deleted() }

        # Address relationship analysis
        let shipping_metro = if this.shipping_address.city != null {
          match {
            this.shipping_address.city.lowercase().re_match(".*(san francisco|sf).*") => "sf_bay_area"
            this.shipping_address.city.lowercase().re_match(".*(los angeles|la).*") => "la_metro"
            _ => "other_urban"
          }
        } else { null }
        root.billing_address.metro_area = $billing_metro
        root.shipping_address.metro_area = $shipping_metro
        root.address_analysis = {
          "same_city": this.billing_address.city == this.shipping_address.city,
          "same_state": this.billing_address.state == this.shipping_address.state,
          "same_metro": $billing_metro == $shipping_metro
        }

        # Remove plaintext addresses
        root.billing_address = root.billing_address.without("street", "zip")
        root.shipping_address = if this.shipping_address != null {
          root.shipping_address.without("street", "zip")
        } else { deleted() }
```

## Verification

When you run data through the updated pipeline, the `billing_address` object will now be protected. The `street` and `zip` fields will be gone, replaced by their encrypted versions and the safe `zip_prefix`. City and state are preserved for your analytics needs. This same pattern can be applied to a `shipping_address` or any other location-based object.
