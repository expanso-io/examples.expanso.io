# Review the Splunk HEC Reference

This path inspects repository artifacts. It does not tail host logs, send a HEC request, or validate a Splunk index.

## Prerequisites

- A checkout of this repository
- A shell with `sed` and `rg`
- No Splunk endpoint or token

## Run the inspection

From the repository root:

```bash
test -f static/pipelines/splunk-production-pipeline.yaml
test -f examples/integrations/splunk-input.yaml
sed -n '1,80p' examples/integrations/splunk-input.yaml
rg -n 'file:|mapping:|http|SPLUNK_HEC_TOKEN' \
  static/pipelines/splunk-production-pipeline.yaml
```

## Expected output

Both file checks exit successfully. The fixture shows synthetic logs, and the final command identifies file input, mapping, HTTP output, and token placeholder.

## Deployment contract

- Mount source logs read-only and `SPLUNK_FALLBACK_PATH` from encrypted persistent storage writable only by Expanso Edge.
- Use a Splunk HEC token limited to the target index, set the HTTPS host and port, and mount `SPLUNK_CA_FILE` read-only.
- Attach an AWS workload identity with prefix-limited `s3:PutObject` and `kms:Encrypt` and `kms:GenerateDataKey` on the selected regional KMS keys; do not mount AWS profiles or access keys.
- Set `S3_BUCKET_PREFIX` to the shared prefix of provisioned buckets with suffixes `us-west`, `us-east`, `eu-west`, and `asia-pacific` (for example, `archive-us-west` for prefix `archive`). Routing retains the residency labels `us_west`, `us_east`, `eu_west`, and `asia_pacific`; restrict the role to those regional prefixes and key-scoped KMS permissions. Supply matching `AWS_REGION_<RESIDENCY>` and `S3_KMS_KEY_ARN_<RESIDENCY>` settings (uppercase residency labels) for each bucket; each key must be in its bucket region.
- Critical Splunk events use 20-record/2-second batching; other events use 100-record/10-second batching.
- Deploy `scripts/metrics/splunk_metrics.py` to the path in `SPLUNK_METRICS_SCRIPT` and mount an encrypted persistent volume for `SPLUNK_METRICS_STATE_PATH`. Grant the workload exclusive access to that state. SQLite preserves labeled event counters and request/processing duration histogram sums and counts across restarts. Retain the event-ID ledger with the state; it deduplicates command retries.
- Set a unique stable `NODE_ID` for each workload and send aggregates to the authenticated HTTPS Pushgateway grouping for that node. Keep one metrics sender per state file and node grouping; duration histograms expose count and sum with an infinite bucket, so they support mean duration rather than quantiles.
- Protect alert outputs with their bearer token, restrict HTTPS egress to approved destinations, and keep retained raw logs under the approved access and deletion policy.

## Cleanup

No files or external resources are created.

## Common failures

- A missing file means the checkout does not contain the referenced artifact.
- No search matches means the reference changed; inspect the complete file before updating this route.
- Syntax inspection does not validate HEC acknowledgement, indexing, or retention behavior.
