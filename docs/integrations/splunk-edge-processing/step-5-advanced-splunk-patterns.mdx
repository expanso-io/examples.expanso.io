# Step 5: Advanced Splunk Patterns

The complete job fans each retained event to Splunk HEC, a residency-selected
archive, an alert branch, and a durable metrics helper. Every external
connection has an explicit security contract.

## Regional KMS-Encrypted Archive

Each residency case uses a provisioned bucket, a same-region KMS key, and the
workload's ambient identity. The identity needs only prefix-limited
`s3:PutObject`, `kms:Encrypt`, and `kms:GenerateDataKey` permissions.

```yaml
output:
  switch:
    cases:
      - check: this.data_residency == "us_west"
        output:
          processors:
            - mapping: |
                root = this.s3_event
                meta = {}
                meta "data-classification" = this.data_classification
                meta "retention-years" = this.retention_years.string()
          aws_s3:
            bucket: ${S3_BUCKET_PREFIX}-us-west
            path: >-
              us_west/${! this.date_partition }/${! this.hour_partition }/expanso-${! uuid_v4() }.jsonl
            region: ${AWS_REGION_US_WEST}
            storage_class: INTELLIGENT_TIERING
            server_side_encryption: aws:kms
            kms_key_id: ${S3_KMS_KEY_ARN_US_WEST}
```

Do not mount an AWS profile or static access key. Restrict network egress to the
selected regional S3 and KMS endpoints.

## Authenticated Alert Branch

```yaml
output:
  http_client:
    url: ${ALERTING_HTTPS_WEBHOOK_URL}
    verb: POST
    headers:
      Content-Type: application/json
      Authorization: Bearer ${ALERT_TOKEN}
    timeout: 5s
    retries: 2
    tls:
      enabled: true
```

The URL must resolve to an approved HTTPS destination. Scope and rotate the
alert token through the deployment secret store.

## Deterministic Health-Check Sampling

The current job keeps failures and a stable ten-percent sample per service and
minute. It does not use a process-local random counter:

```yaml
pipeline:
  processors:
    - mapping: |
        let time_key = now().ts_format("2006-01-02-15-04")
        let service_key = this.host + ":" + (
          this.service.string().catch("unknown")
        )
        let sample_hash = (
          $service_key + ":" + $time_key + ":" + this.message
        ).hash("xxhash64") % 10
        root = if this.event_category != "health_check" {
          this
        } else if this.log_level == "ERROR" || this.log_level == "WARN" {
          this.assign({
            "health_check_sampled": true,
            "sample_reason": "error_condition"
          })
        } else if $sample_hash == 0 {
          this.assign({
            "health_check_sampled": true,
            "sample_reason": "statistical_sample"
          })
        } else {
          deleted()
        }
```

Measure the retained distribution against representative traffic. A fixed hash
rule is deterministic, but it is not proof that downstream analysis remains
valid.

## Durable Metrics

The metrics branch invokes the checked `scripts/metrics/splunk_metrics.py`
helper. Its SQLite state, including the event-ID deduplication ledger, lives on
an encrypted persistent volume. The helper sends Prometheus text exposition to
an authenticated HTTPS Pushgateway grouping for the stable `NODE_ID`.

```yaml
processors:
  - command:
      name: uv
      args_mapping: >-
        root = ["run", "--no-project", env("SPLUNK_METRICS_SCRIPT")]
  - catch:
      - mapping: root = deleted()
output:
  drop: {}
```

Use one metrics sender per state file and node grouping. Mount
`SPLUNK_METRICS_STATE_PATH` from persistent storage writable only by the
workload.

## Explicit Non-Features

The previous tutorial showed adaptive load shedding and anomaly detection with
message metadata as if it were durable rolling state. Those placeholder shapes
were removed. Add either capability only with a defined persistent state store,
concurrency behavior, restart tests, and measured detection or sampling quality.
They are not silently represented as production controls here.
