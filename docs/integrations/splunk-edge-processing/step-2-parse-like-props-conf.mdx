# Step 2: Parse Fields Like props.conf

The complete pipeline selects a parser from the mounted path and record
contents. Parse failures stay visible as authored fields instead of being
silently accepted as structured events.

## JSON With an Explicit Failure Shape

```yaml
pipeline:
  processors:
    - mapping: |
        let parsed = this.raw_message.parse_json().catch(null)
        root = if $parsed.type() == "object" {
          $parsed.merge(this).merge({"parse_success": true})
        } else {
          this.merge({
            "parse_success": false,
            "parse_error": "invalid_json"
          })
        }
```

## CEF Field Extraction

`re_find_object` returns named capture groups. The complete pipeline parses the
extension string separately and classifies the resulting security event.

```yaml
pipeline:
  processors:
    - mapping: |
        let parsed = this.raw_message.re_find_object(
          "^CEF:(?P<version>\\d+)\\|(?P<vendor>[^|]*)\\|" +
          "(?P<product>[^|]*)\\|(?P<device_version>[^|]*)\\|" +
          "(?P<signature_id>[^|]*)\\|(?P<name>[^|]*)\\|" +
          "(?P<severity>[^|]*)\\|(?P<extensions>.*)"
        )
        root = this
        root.cef_parsed = $parsed
```

## Syslog Field Extraction

```yaml
pipeline:
  processors:
    - mapping: |
        let parsed = this.raw_message.re_find_object(
          "^(?P<month>\\w{3})\\s+(?P<day>\\d{1,2})\\s+" +
          "(?P<time>\\d{2}:\\d{2}:\\d{2})\\s+" +
          "(?P<hostname>\\S+)\\s+(?P<process>[^\\[:]+)" +
          "(?:\\[(?P<pid>\\d+)\\])?:\\s*(?P<message>.*)"
        )
        root = this
        root.syslog_parsed = $parsed
        root.process_name = $parsed.process
        root.message = $parsed.message
```

Use `now()` for the collection time and deployment-supplied `NODE_ID` for the
collector identity. Do not substitute zero-argument system-helper placeholders.

## Validation Boundary

```bash
expanso-edge validate \
  static/pipelines/splunk-production-pipeline.yaml
```

Add representative records for every source format before deployment. A regex
that accepts one fixture is not evidence that it covers a production format.
Send records with `parse_success: false` to an observed review path if the
production policy cannot discard them.
