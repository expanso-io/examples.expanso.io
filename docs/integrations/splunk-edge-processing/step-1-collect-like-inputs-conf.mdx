# Step 1: Collect Files Like inputs.conf

The Splunk reference reads newline-delimited records from explicitly mounted
paths. The source mount is read-only, and Expanso Edge runs as an unprivileged
user. Do not grant access to an entire host log directory when the pipeline
needs only a bounded set of files.

## Current File Input

This fragment is taken from the checked complete pipeline:

```yaml
config:
  input:
    file:
      paths:
        - /var/log/applications/*.log
        - /var/log/security/*.log
        - /var/log/system/*.log
        - /opt/app/logs/*.log
      codec: lines
  pipeline:
    processors:
      - mapping: |
          let source_path = metadata("path").or(
            env("SPLUNK_SOURCE_PATH").or("unknown")
          )
          let raw_message = content().string()
          root.raw_message = $raw_message
          root.source_path = $source_path
          root.source_file = $source_path.split("/").index(
            $source_path.split("/").length() - 1
          )
          root.collection_timestamp = now()
          root.host = env("NODE_ID").or("unknown")
```

The `file` input and `metadata("path")` calls are current Expanso Edge syntax.
Deprecated watcher and zero-argument system-helper placeholders are not part of
this example.

## Deployment Contract

- Mount only the configured source paths and make the mount read-only.
- Give the Expanso Edge user read permission without adding privileged groups or
  Linux capabilities.
- Set a unique, stable `NODE_ID` through deployment configuration.
- Run one authoritative reader for a file set unless duplicate delivery is
  acceptable and tested.
- Exercise truncation, rename rotation, copy-truncate rotation, restart, and
  unreadable-file behavior with the log producer used in production.

The input does not create a durable archive. The complete pipeline's HEC
fallback path must be an encrypted persistent volume with access limited to the
Expanso Edge workload.

## Validate the Complete Job

From the repository root:

```bash
expanso-edge validate \
  static/pipelines/splunk-production-pipeline.yaml
```

Validation proves that Expanso Edge accepts the typed job. It does not prove
file rotation semantics or destination delivery.
