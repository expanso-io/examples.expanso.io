# Medical Device Intelligence Configuration Review

This architecture uses synthetic field reports. It does not include a maintained deployment or establish a regulated operating claim.

## Before you adapt it

- Define the field-report schema and reject records that do not match it.
- Package the custom analysis code for the target node and pin its dependencies.
- Encrypt persistent storage and document its retention and deletion policy.
- Use authenticated TLS for every remote destination.
- Give the edge workload only the filesystem, network, and secret access it needs.

## Review path

1. Inspect the explorer and its per-stage input and output.
2. Replace the synthetic fixture with approved test data.
3. Validate the custom analysis code independently.
4. Configure the local result store and remote review destination.
5. Test failure handling before deployment.

The example remains architecture-only until a maintained integration test proves the complete path in the named environment.
