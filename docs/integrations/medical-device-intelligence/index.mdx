## Get started

### Deployment contract

- Mount `MEDICAL_FIXTURE_DIR` read-only and `MEDICAL_REVIEW_PATH` from encrypted persistent storage writable only by the Expanso Edge runtime identity.
- Set `FLEET_HTTPS_URL` to the approved fleet-service origin, load `FLEET_API_TOKEN` from the secret manager, and mount the CA plus client certificate and key read-only for mTLS.
- Restrict egress to that fleet origin. Scope the bearer token to review-candidate submission only and apply the healthcare retention policy to both local and fleet copies.
- The optional analysis script uses the authenticated Anthropic subscription CLI when explicitly enabled; it does not accept a metered API key and the edge workload receives no provider credential.

Validate `docs/integrations/medical-device-intelligence/pipeline.yaml` with Expanso Edge before deploying the job through Expanso Cloud. The fixtures and authored fallback are synthetic; this example is not a clinical decision system.
