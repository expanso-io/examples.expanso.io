# Step 2: Normalize Currency

Convert all transaction amounts to USD while preserving original values. The pipeline reads approved, dated rates from the governed Db2 `CURRENCY_RATES` table.

## The Goal

- Convert `AMOUNT` from any currency to USD
- Preserve `original_amount` and `original_currency` for reconciliation
- Create `amount_usd` as the normalized field

## DataStage Equivalent

In DataStage, currency conversion typically requires:

1. **Lookup Stage** reading from a rates table
2. **Transformer Stage** applying the conversion
3. **Database connection** to fetch current rates
4. **Caching logic** to avoid repeated lookups

The Db2 role needs read access to the rates table. Maintain a unique `(CURRENCY, RATE_DATE)` key and a positive numeric `USD_RATE`, including USD, for each supported transaction date.

## Implementation

Add the currency processor after lineage:

```yaml title="step-2-currency.yaml"
pipeline:
  processors:
    - branch:
        request_map: |
          root.currency = this.CURRENCY
          root.rate_date = this.TRANSACTION_DATE
        processors:
          - sql_select:
              driver: odbc
              dsn: Driver={IBM DB2 ODBC Driver};Database=${DB2_DATABASE};Hostname=${DB2_HOST};Port=${DB2_TLS_PORT};Protocol=TCPIP;Uid=${DB2_USER};Pwd=${DB2_PASSWORD};Security=SSL;SSLServerCertificate=${DB2_CA_CERT};
              table: CURRENCY_RATES
              columns:
                - USD_RATE
              where: CURRENCY = ? AND RATE_DATE = ?
              args_mapping: root = [this.currency, this.rate_date]
          - mapping: |
              root = if this.length() != 1 {
                throw("Expected one governed USD rate for the transaction date")
              } else { this.index(0) }
          - mapping: |
              root = if this.USD_RATE.type() != "number" || this.USD_RATE <= 0 {
                throw("Invalid governed USD rate")
              } else { this }
        result_map: |
          root.original_amount = root.AMOUNT
          root.original_currency = root.CURRENCY
          root.amount_usd = (root.AMOUNT.number() * this.USD_RATE * 100).round() / 100
```

## Expected behavior

The branch keeps the original transaction and adds `original_amount`, `original_currency`, and `amount_usd`. For a synthetic EUR amount of 125.50 and an approved rate of 1.08, `amount_usd` is 135.54. Rates are data supplied by the governed table, never constants in the pipeline.

A missing, duplicate, or nonpositive rate produces a processing error. The complete pipeline deletes errored messages at the shared output boundary, so they cannot reach BigQuery.
