# Complete Pipeline

<CopyPipelineButton pipeline={pipelineYaml} />

This HTTP reference converts JSON, CSV, and XML. It detects the source from
the payload, chooses the response format from the `Accept` header, and returns
the result to the originating request.

## Quick Test

```bash
# Request CSV output from JSON input
curl -X POST http://localhost:8080/transform \
  -H "Content-Type: application/json" \
  -H "Accept: text/csv" \
  -d '{
    "sensor_id": "temp-001",
    "temperature": 72.5,
    "humidity": 45.0,
    "timestamp": "2024-01-15T10:30:00Z"
  }'

# Response contains the CSV header and values
```

## Deploy

```bash
# Deploy to Expanso orchestrator
expanso-cli job deploy transform-formats.yaml

# Or run locally with expanso-edge
expanso-edge run --config transform-formats.yaml
```
