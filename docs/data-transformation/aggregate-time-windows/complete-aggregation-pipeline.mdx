## Input and window boundary

The displayed configuration consumes the `sensor-events` Kafka topic. Each
record needs `sensor_id`, `timestamp`, and numeric `temperature`; optional
`location` and `facility` fields support rollups. The `system_window` buffer
accumulates events before grouping by value and computing batch statistics.
It does not implement inactivity-based session windows.

The download below is the simpler one-minute HTTP aggregation variant at
`/sensors/readings`, rather than the Kafka configuration displayed here.
