# Complete pipeline

- **HTTP input** — events arrive at `POST /events`
- **Jev branch** — one interestingness score per event
- **Sampling cascade** — 100% of score ≥ 3, deterministic 1% of the rest
- **Fan-out** — stdout plus kept/sampled files

## How it works, stage by stage

1. **Parse** — `json_documents` parses the event.
2. **Ask Jev** — a single Score question rates interestingness 0–4.
3. **Sample** — one `mapping` keeps the event if the score is ≥ 3 or the counter hits every 100th; otherwise the event is `deleted()`. Survivors are stamped with `jev_score` and `jev_decision`.
4. **Route** — stdout plus `kept`/`sampled` files.

## Try it

```bash
# 1. Mock Jev (no API key needed)
python3 examples/jev-mock-server.py &

# 2. Run the pipeline
JEV_API_URL=http://localhost:8099/v1/systemone \
  expanso-edge run --config examples/log-processing/jev-smart-sampling.yaml

# 3. Send the sample events
while read -r line; do
  curl -s -X POST http://localhost:8080/events \
    -H "Content-Type: application/json" -d "$line" > /dev/null
done < examples/log-processing/jev-smart-sampling-input.jsonl
```

The panic and the slow query should land in `kept-*.jsonl`; the health checks mostly vanish, with every 100th surviving in `sampled-*.jsonl`.

## With a real Jev key

```bash
export TYPESAFE_API_KEY="your-key"
expanso-edge run --config examples/log-processing/jev-smart-sampling.yaml
```

Put this in front of your log aggregator and watch the ingest bill fall.
